# Fehlerbehebung

Wenn der Manager Migrationen anfordert, verwenden Sie den Befehl unter [Erste Schritte](./getting-started.md).

Prüfen Sie `save_document` in der Managerrolle, falls Anlegen oder Bearbeiten nicht verfügbar ist. Wählen Sie bei einem belegten Slug einen anderen Wert. Für die Seitenverknüpfung benötigen Sie die ID einer vorhandenen Evo-Ressource.
