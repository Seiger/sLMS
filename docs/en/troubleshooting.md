# Troubleshooting

If the manager prompts you to run migrations, use the command in [Getting started](./getting-started.md).

If the create or edit action is unavailable, check the manager role for `save_document`. If the slug is already taken, choose another. Use the ID of an existing Evo resource when linking a page.
