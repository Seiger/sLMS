# Manage courses

**Overview** shows the number of courses, modules and lessons, the share of published courses and drafts, and the number of courses created today, in the last 7 days and in the last 30 days. Both periods include today.

In **Courses**, search by title or slug, filter by publication status, and switch between table and list views. Select **Create course** to add a record. To edit an existing course, select its row and click **Edit**.

Enter a title. Add a description, the ID of a public Evo page and a publication status as needed. If the slug is blank, sLMS derives it from the title on creation or keeps the existing slug on edit.

## Modules and lessons

In a course row, select **Modules** to open the course outline. In a module row, select **Lessons** to see its lessons. Use the button above the table to go up one level.

Select **Create module** or **Create lesson**. To edit a record, use the pencil button in its row. The module form has a description field and the lesson form has a content field. New records are drafts unless you mark them as published.

New records appear at the end of the list. Drag a row by its handle or use the arrows in the **Order** column. The new order is saved immediately.
