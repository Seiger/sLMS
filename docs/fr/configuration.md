# Configuration

sLMS utilise la langue et le thème du gestionnaire Evo. Le paquet fournit les traductions `uk`, `en`, `de`, `fr`, `pl` et `ru`.

La consultation requiert l’accès au module sLMS et l’autorisation Evo `exec_module`. La création et la modification nécessitent également `save_document`.
