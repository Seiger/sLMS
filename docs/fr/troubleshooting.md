# Résolution des problèmes

Si le gestionnaire demande d’appliquer les migrations, utilisez la commande indiquée dans [Premiers pas](./getting-started.md).

Si la création ou la modification est indisponible, vérifiez l’autorisation `save_document` du rôle. Si le slug est déjà utilisé, choisissez-en un autre. Pour lier une page, utilisez l’ID d’une ressource Evo existante.
