# Konfiguracja

sLMS korzysta z języka i motywu panelu Evo. Pakiet zawiera tłumaczenia dla `uk`, `en`, `de`, `fr`, `pl` i `ru`.

Do przeglądania kursów potrzeba dostępu do modułu Kursy i uprawnienia Evo `exec_module`. Tworzenie i edycja wymagają także `save_document`.
