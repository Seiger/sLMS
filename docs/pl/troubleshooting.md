# Rozwiązywanie problemów

Gdy panel prosi o przeprowadzenie migracji, użyj polecenia z rozdziału [Pierwsze kroki](./getting-started.md).

Jeśli tworzenie lub edycja są niedostępne, sprawdź uprawnienie `save_document` w roli. Jeśli slug jest zajęty, wybierz inny. Do powiązania strony użyj ID istniejącego zasobu Evo.
