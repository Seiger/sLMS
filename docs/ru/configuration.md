# Настройка

sLMS использует язык и тему менеджера Evo. В пакете есть переводы для `uk`, `en`, `de`, `fr`, `pl` и `ru`.

Просмотр требует доступа к модулю «Курсы» и разрешения Evo `exec_module`. Для создания и редактирования также требуется `save_document`.
