# Руководство разработчика

`Seiger\sLMS\sLMSServiceProvider` регистрирует миграции и модуль менеджера. Панель `slms.module-panel` использует компоненты Evo UI. Пресет `slms.courses` определяет таблицу и форму курсов.

Переводы хранятся в `lang/<locale>/global.php`. Обновляйте эти страницы вместе с кодом и проверяйте пакет на PHP 8.4, 8.5 и 8.6.

## Доступ к прохождению

Маршрут `slms.assessment.entry` принимает ID модуля в параметре `module`. Пакет проверяет веб-сессию Evo и публикацию курса и модуля. Для дополнительных правил доступа привяжите в контейнере свою реализацию `Seiger\sLMS\Support\AssessmentAccess`. `slms.attempts.pass_percent` принимает целое число от 0 до 100 и применяется к новым версиям теста.
