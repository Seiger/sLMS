# Справочник

Каталог имеет три уровня. `Course` (`s_lms_courses`) содержит записи `Module` (`s_lms_modules`), а модуль содержит записи `Lesson` (`s_lms_lessons`). Модули и уроки упорядочены по позиции и ID.

Название обязательно. Slug уникален для всех курсов и состоит из строчных латинских букв, цифр и дефисов между словами. ID ресурса необязателен и должен указывать на существующий, не удалённый ресурс Evo. Новый курс по умолчанию сохраняется как черновик.

Slug модуля уникален в пределах курса, а slug урока — в пределах модуля. Изменение порядка сохраняет ID записей и их связи с курсом и модулем.

В каждом модуле может быть один редактируемый тест `Assessment` (`s_lms_assessments`). Тест создаётся при сохранении первого вопроса. Вопросы (`AssessmentQuestion`, `s_lms_assessment_questions`) и варианты (`AssessmentOption`, `s_lms_assessment_options`) сохраняют порядок. Правильность задаётся отдельно для каждого варианта.
