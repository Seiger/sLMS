# Устранение проблем

Если менеджер предлагает выполнить миграции, используйте команду из раздела [Начало работы](./getting-started.md).

Если создание или редактирование недоступно, проверьте разрешение `save_document` в роли. Если slug уже занят, укажите другой. Для привязки страницы понадобится ID существующего ресурса Evo.
