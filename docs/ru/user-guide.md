# Управление курсами

**Обзор** показывает количество курсов, модулей и уроков, долю опубликованных курсов и черновиков и количество курсов, созданных сегодня, за последние 7 и 30 дней. Оба периода включают сегодняшний день.

В разделе **Курсы** можно искать по названию или slug, фильтровать по статусу публикации и переключаться между таблицей и списком. Чтобы добавить запись, нажмите **Создать курс**. Для изменения выберите нужную строку и нажмите **Редактировать**.

Укажите название. При необходимости добавьте описание, ID публичной страницы Evo и статус публикации. Если slug пуст, sLMS сформирует его из названия при создании курса или сохранит прежнее значение при редактировании.

## Модули и уроки

В строке курса нажмите **Модули**, чтобы открыть его программу. В строке модуля нажмите **Уроки**, чтобы увидеть его уроки. Кнопка над таблицей возвращает на предыдущий уровень.

Нажмите **Создать модуль** или **Создать урок**. Для редактирования нажмите кнопку с карандашом в нужной строке. В форме модуля можно указать описание, а в форме урока — его содержание. Новые записи остаются черновиками, если их не отметить как опубликованные.

Новая запись добавляется в конец списка. Чтобы изменить порядок, перетащите строку за ручку или воспользуйтесь стрелками в столбце **Порядок**. Порядок сохраняется сразу.

## Тест модуля

В строке учебного модуля нажмите **Тест**. В списке вопросов нажмите **Создать вопрос** или кнопку с карандашом в строке существующего вопроса.

Введите вопрос и хотя бы два варианта ответа. Отметьте каждый правильный вариант флажком **Правильный ответ**. В форме можно добавлять, удалять и перемещать варианты. Сохраните вопрос, чтобы применить изменения.

Пользователь с правом только на просмотр видит вопросы и количество вариантов. Редактор и ключ ответов доступны с правом редактирования.
