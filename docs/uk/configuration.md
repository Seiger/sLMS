# Налаштування

sLMS використовує мову й тему менеджера Evo. У пакеті є переклади для `uk`, `en`, `de`, `fr`, `pl` та `ru`.

Для перегляду потрібен доступ до файлового модуля sLMS і дозвіл Evo `exec_module`. Створення й редагування також потребують дозволу `save_document`.
