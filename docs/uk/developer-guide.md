# Посібник розробника

Провайдер `Seiger\sLMS\sLMSServiceProvider` реєструє міграції та модуль менеджера. Панель `slms.module-panel` використовує компоненти Evo UI, а `slms.courses` задає таблицю і форму курсів.

Переклади пакета зберігаються в `lang/<locale>/global.php`. Оновлюй цю документацію разом із функціоналом і перевіряй виконання на PHP 8.4, 8.5 та 8.6.
