# Довідник

Навчальна структура має три рівні. `Course` (`s_lms_courses`) має модулі `Module` (`s_lms_modules`), а модуль має уроки `Lesson` (`s_lms_lessons`). Модулі й уроки впорядковуються за позицією та ID.

Назва курсу обов’язкова. Slug унікальний для всіх курсів і складається з малих латинських літер, цифр і дефісів між словами. ID ресурсу необов’язковий; указаний ресурс Evo має існувати й не бути видаленим. Новий курс за замовчуванням є чернеткою.

Slug модуля унікальний у межах курсу, а slug уроку — у межах модуля. Зміна порядку зберігає ID записів і їхні зв’язки з курсом та модулем.

Кожен модуль може мати один редагований тест `Assessment` (`s_lms_assessments`). Перший збережений запис створює тест. Питання `AssessmentQuestion` (`s_lms_assessment_questions`) і варіанти `AssessmentOption` (`s_lms_assessment_options`) зберігають порядок. Правильність позначається для кожного варіанта.

`AssessmentVersion` (`s_lms_assessment_versions`) фіксує питання, варіанти, ключ і прохідний бал. `AssessmentAttempt` (`s_lms_assessment_attempts`) зберігає вебкористувача, обрані відповіді, час завершення й результат. За питання нараховується один бал, якщо вибрано рівно всі правильні варіанти. Відсоток округлюється вгору. За замовчуванням прохідний бал становить 70%.
