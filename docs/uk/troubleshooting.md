# Усунення проблем

Якщо менеджер просить застосувати міграції, виконай команду зі сторінки [Початок роботи](./getting-started.md).

Якщо створення або редагування недоступне, перевір дозвіл `save_document` у ролі менеджера. Якщо slug зайнятий, укажи інший. Для прив’язки сторінки потрібен ID наявного ресурсу Evo.
